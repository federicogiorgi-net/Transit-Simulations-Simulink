# Transit-Simulations-Simulink
 This repository contains two Simulink models that simulate vehicle dynamics, operations, and energy  for: Bus Line 73 (Duomo → Linate)** — articulated hybrid-electric bus with series architecture (IVECO Urbanway 18).   - Metro Line 4 (M4, Milan) — driverless metro train, including energy/adhesion and lateral dynamics on curved track.
